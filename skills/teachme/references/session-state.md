# Session State

Use this reference when Rung teaching spans multiple sessions or when a compact handoff is useful.

Preserve only forward-relevant learning state and keep **one canonical current view**. Old session transcripts and summaries are evidence/history, not parallel current truth.

For a single skill:

```text
MODE: TEACHING | OUTPUT
SUBJECT/DOMAIN:
CURRENT SKILL:
CURRENT STATUS: NEEDS_BASELINE | GUIDED | PRACTICING | TRANSFER_TEST | INDEPENDENT | BLOCKED_ON_PREREQUISITE
INDEPENDENT SUCCESS:
FINAL MASTERY PROOF:
VERIFIED STRENGTHS:
ACTIVE WEAKNESSES:
CURRENT DIAGNOSTIC QUESTIONS:
STANDING PRINCIPLES:
LAST MASTERY EVIDENCE:
CURRENT BLOCKER:
EXACT NEXT EXERCISE:
USEFUL BUT LATER:
```

For a multi-skill learning arc, extend the same canonical state rather than creating another tracker:

```text
ARC GOAL:
FINAL INDEPENDENT PROOF:
CURRENT PHASE:
CAPABILITY MAP / ROADMAP:
MASTERY EVIDENCE:
ACTIVE REGRESSION CASES:
PREREQUISITE BLOCKERS:
```

## State rules

- Record demonstrated strengths as VERIFIED; do not promote self-report to verified competence without evidence.
- A consequential mastery status should point to the fresh evidence that justified it.
- Keep diagnostic questions that remain useful for future self-checking.
- Treat new reusable lessons as candidates before promoting them to standing principles.
- Carry only active regression cases that can affect future teaching; retire stale ones.
- Update the roadmap when trajectory evidence changes the useful route to the final proof.
- Do not keep trivial slips or personal trivia unless they materially change teaching decisions.
- Prefer compact current state over replaying an entire old conversation.

Use state for continuity, not ceremony. Small one-off lessons do not require a formal state record.
