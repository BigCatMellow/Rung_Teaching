# Session State

Use this reference when Rung teaching spans multiple sessions or when a compact handoff is useful.

Preserve only forward-relevant learning state.

Keep **one canonical current state**. Old session transcripts and summaries are evidence/history, not parallel current truth.

```text
MODE: TEACHING | OUTPUT
SUBJECT/DOMAIN:
CURRENT SKILL:
CURRENT STATUS: NEEDS_BASELINE | GUIDED | PRACTICING | TRANSFER_TEST | INDEPENDENT | BLOCKED_ON_PREREQUISITE

INDEPENDENT SUCCESS:
FINAL MASTERY PROOF:

VERIFIED STRENGTHS:
- ...

ACTIVE WEAKNESSES:
- ...

CURRENT DIAGNOSTIC QUESTIONS:
- ...

STANDING PRINCIPLES:
- ...

REPEATED FAILURE PATTERNS:
- ...

LAST MASTERY EVIDENCE:
- ...

CURRENT BLOCKER:
- ...

EXACT NEXT EXERCISE:
- ...

USEFUL BUT LATER:
- ...
```

For a multi-skill Learning Arc, extend the same state rather than creating another tracker:

```text
ARC GOAL:
FINAL INDEPENDENT PROOF:
CURRENT PHASE:
CAPABILITY MAP / ROADMAP:
MASTERY EVIDENCE:
ACTIVE REGRESSION CASES:
PREREQUISITE BLOCKERS:
```

## State rules

- Record demonstrated strengths as VERIFIED; do not promote self-report to verified competence without evidence.
- Keep diagnostic questions that are still useful for future self-checking.
- Treat new reusable lessons as candidates before promoting them to standing principles.
- Retire or revise standing principles when evidence contradicts them.
- Carry only active regression cases that can affect future teaching; retire stale ones.
- Update the Learning Arc roadmap when trajectory evidence changes the useful route to the final proof.
- Do not keep trivial slips or personal trivia unless they materially change teaching decisions.
- Prefer this compact state over replaying an entire old conversation.

## Status meanings

### NEEDS_BASELINE
Current ability has not been demonstrated.

### GUIDED
The learner still needs substantial cues, explanations, or examples.

### PRACTICING
The learner can perform with light prompting and is consolidating the skill.

### TRANSFER_TEST
The practiced form works; independence is being tested on variation.

### INDEPENDENT
The learner passed the defined mastery proof without material help.

### BLOCKED_ON_PREREQUISITE
A missing concept or fact prevents productive practice of the target skill.

Use states for clarity, not ceremony. Small one-off lessons do not require a formal state record.
